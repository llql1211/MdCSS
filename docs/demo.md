# .MdCSS 功能示例

这个文件把 MdCSS 的语法集中演示了一遍。用 MPE 打开本文件，所见即所得；每一节都是「代码 → 效果」的对照，效果就是预览里紧跟在代码后面的内容。

> [!IMPORTANT]
> 本示例假设产物由 `--enable-parser` 生成（图标题、表格合并、多列布局、自动标题编号都依赖它）。若还没生成，先执行 `pixi run python mdcss.py --enable-parser`；只用纯 CSS 模式时，标注了「需要 parser」的内容不会生效。完整参数见 [参数说明](https://github.com/suif4599/mdcss/blob/main/docs/config.md)

## .图片

### .宽度与对齐

图片控制串的完整形式是 `![控制串|图标题|alt](src)`，控制串按顺序写「宽度 对齐字母 效果字母」。宽度可以写 `%`（封顶 100）或 `px`；不写对齐字母时图片默认居中。

|||-

代码：

```markdown
![40%|.宽度 40%、默认居中](./assets/image.jpeg)

![25%R|.宽度 25%、靠右对齐](./assets/image.jpeg)
```

|||

效果：

![40%|.宽度 40%、默认居中](./assets/image.jpeg)

![25%R|.宽度 25%、靠右对齐](./assets/image.jpeg)

-|||

### .文字环绕

在控制串里加 `Lf`/`Rf`，图片会浮动到左侧/右侧，正文自动环绕。

|||-

代码：

```markdown
![40%Lfi|.浮动到左侧的图片](./assets/image.jpeg)

正文会自动环绕在图片右侧……
```

|||

效果：

![40%Lfi|.浮动到左侧的图片](./assets/image.jpeg)

图片浮动到左侧后，这一段正文会自动环绕在它的右侧，不需要另外写 HTML 或调整容器宽度。段落写满一行后继续向下排版，遇到图片下边缘才恢复整行宽度。

-|||

### .单行多图与子图编号

给图片加上对齐字母 `r`（行内块），连续几张就会排成一行，宽度之和不超过 100% 即可。把总标题写成 `(.总标题)` 附在任意一张的图标题后面，各张的短标题会自动生成 `(a)(b)(c)` 子图编号，整体再占一个图号。

下面的例子用同一张图分别套四种效果字母，字母含义见下一节的表格。

|||-

代码：

```markdown
![24%r|.原图(.色轮)](./assets/colorwheel.png) ![24%ri|.反相](./assets/colorwheel.png) ![24%rI|.亮度两端互换](./assets/colorwheel.png) ![24%rm|.去除背景](./assets/colorwheel.png)
```

|||

效果：

![24%r|.原图(.色轮)](./assets/colorwheel.png) ![24%ri|.反相](./assets/colorwheel.png) ![24%rI|.亮度两端互换](./assets/colorwheel.png) ![24%rm|.去除背景](./assets/colorwheel.png)

-|||

### .特殊效果

控制串里的效果字母直接作用于图片本身，写在宽度之后（宽度不能省略，例如 `![100%i](src)`）。

Table: .效果字母

| 字母 | 作用 | 说明 |
| :--: | :---: | --- |
| `i` | 反相 | 纯 CSS 滤镜，预览与导出均生效 |
| `m` | 去除背景 | 纯 CSS 混合模式，预览与导出均生效 |
| `I` | 亮度两端互换 | 实验性，需 canvas 运行时脚本，导出时还原 |
| `M` | 亮部抠图＋暗部提亮 | 实验性，需 canvas 运行时脚本，导出时还原 |

> [!NOTE]
> `I`/`M` 依赖 head.html 里的 canvas 运行时脚本，MPE 0.8.36 起会剥除内联脚本，需按 [MPE 补丁说明](https://github.com/suif4599/mdcss/blob/main/docs/mpe_patch.md) 处理；未打补丁时它们在 MPE 里不生效，inkstone 桥接与在线预览不受影响。`I`/`M` 还支持写成 `I(下界,上界)` 逐图指定亮度阈值

## .表格

### .合并单元格

在单元格里写 `c2:`（横向合并 2 格）、`r2`（纵向合并 2 格），被吃掉的位置用 `\` 占位；前面加 `:` 表示居中。

|||-

代码：

```markdown
Table: .合并单元格

| 方法 | 数据集 A | 数据集 B | 均值 |
| --- | --- | --- | :---: |
| 本文 | 95.2% | :c2: 96.1% | \ |
| 基线 | 88.7% | 91.0% | 89.9% |
```

|||

效果：

Table: .合并单元格

| 方法 | 数据集 A | 数据集 B | 均值 |
| --- | --- | --- | :---: |
| 本文 | 95.2% | :c2: 96.1% | \ |
| 基线 | 88.7% | 91.0% | 89.9% |

-|||

### .表标题与斑马纹

`Table:` 后面跟 `.标题` 生成「表 N: 标题」并自动编号；默认按内容自动决定是否加斑马纹，也可以用 `Table<zebra>` / `Table<nozebra>` 强制指定。

|||-

代码：

```markdown
Table<zebra>: .强制斑马纹的表格

| 列 1 | 列 2 |
| --- | --- |
| 内容 | 内容 |
| 内容 | 内容 |
```

|||

效果：

Table<zebra>: .强制斑马纹的表格

| 列 1 | 列 2 |
| --- | --- |
| 内容 | 内容 |
| 内容 | 内容 |

-|||

## .多列布局

用 `|||-` 开始、`|||` 分列、`-|||` 结束。列参数可选：数字指定列宽（默认平均分配），前面加 `:` 向上对齐、两端各一个 `:` 居中、末尾一个 `:` 向下对齐。

```markdown
|||-30

**左栏** 宽 30%

|||:40:

**中栏** 宽 40%、垂直居中

|||:

**右栏** 占剩余宽度、底部对齐

-|||
```

效果：

|||-30

**左栏** 宽 30%

|||:40:

**中栏** 宽 40%、垂直居中

|||:

**右栏** 占剩余宽度、底部对齐

-|||

## .正文增强

Callout 在打印时不会跨页断开，折叠形式的 Callout 在打印中会展开。

> [!TIP]
> 这是一个 TIP 类型的 Callout，MPE 原生支持，MdCSS 改进的是它的打印行为。

> [!WARNING]-
> 这是一个默认折叠的 Callout（`[!WARNING]-`），点击标题可以展开。打印/导出时会被展开，不会丢掉内容。

代码块加 `{.line-numbers}` 显示行号，MdCSS 修复了行号与代码错位的 bug（属于导出时生效的排版修复）。

```javascript {.line-numbers}
function add(x, y) {
  return x + y
}
```

段落缩进是文档级开关：在文件开头写 `@indent`，全篇正文的首行就会缩进两个字符。本示例没有开启，以免影响上面各节的排版。

## .说明

- 以上语法在 MPE 与 inkstone 桥接中均可使用，差异见 [SYNTAX.md 的语法速查](https://github.com/suif4599/mdcss/blob/main/docs/SYNTAX.md)
- 部分效果只在打印/导出时可见：代码行号修复、长代码不另起一页、Callout 打印不跨页、表格打印配色、`i`/`m` 效果还原
- `I`/`M` 与「非 ASCII 文件名修复」需要 canvas 运行时脚本，详见 [MPE 补丁说明](https://github.com/suif4599/mdcss/blob/main/docs/mpe_patch.md)
